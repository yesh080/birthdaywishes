# Deploy Birthday Surprise Website to Vercel

## 🚀 Quick Deployment Steps

### Method 1: Vercel CLI (Recommended)
1. **Install Vercel CLI**
   ```bash
   npm install -g vercel
   ```

2. **Login to Vercel**
   ```bash
   vercel login
   ```

3. **Deploy from your project folder**
   ```bash
   cd birthday-surprise
   vercel
   ```

4. **Follow the prompts** - Vercel will detect it's a static site and deploy it!

### Method 2: Vercel Web Dashboard
1. Go to [vercel.com](https://vercel.com)
2. Click "New Project"
3. Upload your `birthday-surprise` folder or connect to GitHub
4. Click "Deploy"

### Method 3: Drag & Drop
1. Compress your `birthday-surprise` folder to a ZIP file
2. Go to [vercel.com](https://vercel.com)
3. Drag and drop the ZIP file onto the page
